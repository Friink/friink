# Friink Design

## Product Direction

Friink is a calm, people-first social space centered on meaningful conversations and connection.

## Layout

- Desktop uses a persistent sidebar and a main content panel.
- Mobile uses a bottom navigation bar.
- The shared header contains the current page title, Search, and Notifications.
- Feed content is centered with a readable maximum width.

## Navigation

The sidebar order is:

1. Home
2. Profile
3. Connections
4. Starred
5. Post
6. Messages
7. Settings

## Feed Behavior

- Home defaults to the `All` filter and also supports `Connections`.
- Connections is a people directory with `All`, `Followers`, `Following`, and `Requests` views.
- Starred is a preset feed containing only starred posts.
- Starred posts use the brand-colored filled star icon.

## Visual Language

- Primary brand color is used for active states, selected tabs, links, and important actions.
- Ink and muted gray provide the primary text hierarchy.
- Thin lines separate navigation, tabs, feed posts, and directory rows.
- Avatars use circular shapes and soft color variations.
- Controls should remain compact, clear, and usable on narrow screens.

## Components

Standard app surfaces should be reusable components. Page-specific content may remain local when it is not reused elsewhere.
